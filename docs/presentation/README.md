# Apresentação da aula

Desenvolvida para as aulas de **Introdução à Inteligência Artificial**, com explicação em português e termos técnicos em inglês.

- `TinyML_BitDogLab_Aula.pptx`: 28 slides editáveis; quatro gráficos e sete tabelas nativas, com 28 notas de fala.
- `TinyML_BitDogLab_Aula.pdf`: cópia visual para projeção, com a mesma aparência dos renders revisados.
- `speaker-notes.md`: roteiro sugerido de 25 minutos mais demonstração.
- [Guia matemático](../Guia_TinyML_Matematica_e_Experimento.pdf): dez páginas com fórmulas, contas e resultados.
- [Novo benchmark](../new-benchmark.md): CPU/RTX/placa e Float32/INT8, com limites de comparação.

O deck distingue training (2.066 recordings, 568 grupos, 28.340 windows), seis exemplos do painel e os resultados do test completo. Dois exemplos continuam embutidos na demonstração autônoma; os outros quatro podem ser enviados pelo painel USB, sem regravar a placa.

Execute START_WINDOWS.cmd para abrir o painel. Mostre primeiro a escuta e a inference do PC, depois o mesmo PCM na placa com firmware compatível. BOOTSEL é usado para gravar, não para executar o benchmark. O microfone permanece experimental.

O PPTX foi inspecionado por render e validado estruturalmente; os gráficos têm dados próprios incorporados. Isso não representa um ensaio em PowerPoint nativo nem validação acústica do microfone.
