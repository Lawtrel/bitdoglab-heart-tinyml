# Apresentação da aula

Projeto desenvolvido nas aulas de **Introdução à Inteligência Artificial**.

- `TinyML_BitDogLab_Aula.pptx`: 18 slides editáveis com notas de fala.
- `TinyML_BitDogLab_Aula.pdf`: cópia visual para projetar.
- `speaker-notes.md`: roteiro, referências e sugestões de tempo.

Proposta de 15 a 18 minutos. Para reduzir, pule o gráfico de F1 que repete a tabela e use apenas um exemplo digital e uma tentativa acústica.

Os slides e o roteiro preservam a versão didática de 24/10/2026. Há referências a iniciadores históricos: neste repositório, use **START_WINDOWS.cmd** ou `heart-tinyml serve`; para compilar/gravar, siga `../firmware.md`. Nenhum executável com caminho particular é obrigatório.

Comece com o modo PC. A comparação USB depende do firmware demo e de ensaio físico. Em caso de falha, apresente os resultados científicos preservados e explique a limitação da demonstração ao vivo.
