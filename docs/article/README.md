# Artigo em desenvolvimento

Este artigo é desenvolvido durante as aulas de **Introdução à Inteligência Artificial** e utiliza o projeto TinyML/BitDogLab como estudo experimental. O evento de interesse é o VI Simpósio Baiano de Modelagem e Simulação de Biossistemas.

- `english/main.tex`: versão em inglês.
- `portuguese/main.tex`: versão de apoio em português.

As fontes foram preservadas do material existente. Este repositório não representa submissão, aceitação ou publicação. Autoria final, contatos, ORCID, regras/prazo e revisão visual devem ser conferidos antes de qualquer envio. A versão portuguesa é material de apoio; verifique o idioma exigido pelo evento.

As fontes incluem figuras, bibliografia e a classe do template. Em uma instalação LaTeX local, compile `main.tex` e sua bibliografia. O [projeto TinyML no Overleaf](https://www.overleaf.com/project/6ad7b0df6f30cdfb4d8e1f58) foi atualizado em 27/10/2026, preservando o template oficial e um backup local anterior. main.tex em inglês é o documento principal; main_pt.tex é a versão de apoio em português. As duas versões compilaram com seis páginas, incluindo referências.

Os comentários de tarefas no TeX e notas históricas de compilação pertencem à fase original. Para estado atual de evidências, consulte `../results.md`.
